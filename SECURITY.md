# Segurança

## Versões com suporte

Só a [versão mais recente](https://github.com/lux-insider/trainer-re5-tu5/releases/latest)
recebe correções.

## Como relatar uma falha de segurança

**Não abra uma issue pública.** Use a aba
[**Security → Report a vulnerability**](https://github.com/lux-insider/trainer-re5-tu5/security/advisories/new)
do repositório: o relato fica privado até a correção sair.

Conte o que acontece, como repetir e, se possível, um arquivo de exemplo
(sem dados pessoais). A resposta vem em até 7 dias.

## Cuidados do trainer

- Antes de alterar a memória, confere o Title ID e as instruções originais do
  jogo; se algo não bater, não altera nada.
- Funciona só offline, em consoles RGH/JTAG.
